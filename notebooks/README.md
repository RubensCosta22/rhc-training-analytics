# Notebooks

Os notebooks deste diretório documentam as etapas do pipeline de dados.

| Notebook | Objetivo |
|---|---|
| `01_bronze_extract.ipynb` | Extrair os dados da origem e construir a camada Bronze. |
| `02_silver_transform.ipynb` | Limpar, padronizar e transformar os dados. |
| `03_gold_model.ipynb` | Construir fatos, dimensões, métricas e datasets analíticos. |
| `04_data_quality.ipynb` | Executar testes e validações de qualidade. |

Os notebooks serão desenvolvidos no Google Colab e versionados sem credenciais ou dados privados.
